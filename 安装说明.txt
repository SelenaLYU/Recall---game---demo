检查：在 VS Code 终端运行 npm.cmd run build，再运行 npm.cmd run dev。
开始游戏后先看到“正在加载开场动画”约 4 秒；动画结束或跳过后，
“正在走进森林”至少 4 秒，然后出现森林。房间收音机四档依次为：
杂音、风声、公公没有离开你、念亲恩。切换频道或关闭面板会停掉上一段。
